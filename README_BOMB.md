# 💣 커피내기 폭탄 돌리기 사용 설명서 ☕

이 문서는 **'커피내기 폭탄 돌리기(coffee-bomb.html)'** 게임을 처음 사용하는 분들을 위한 상세 가이드입니다. 사무실의 긴장감을 높여줄 최고의 복불복 게임을 즐겨보세요!

---

## 🎮 게임 소개
이 게임은 보이지 않는 **랜덤 타이머**가 작동하는 동안 폭탄을 다음 사람에게 넘기는 방식입니다. 타이머가 끝나는 순간 폭탄을 들고 있는 사람이 오늘의 커피 당첨자입니다!

---

## 🚀 시작하기 (3단계)

1.  **게임 열기**: `coffee-bomb.html` 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 엽니다.
2.  **명단 입력**: 화면 중앙의 큰 칸에 참여자들의 이름을 한 줄에 한 명씩 입력합니다.
    *   *예시:*
        ```
        홍길동
        김철수
        이영희
        ```
3.  **게임 시작**: [게임 시작!] 버튼을 누르면 즉시 긴장 넘치는 무지개 배경과 함께 게임이 시작됩니다.

---

## 🕹️ 게임 규칙
*   **폭탄 넘기기**: 자신의 이름이 화면에 보이면, 재빨리 [폭탄 넘기기!] 버튼을 누르세요. 폭탄이 다음 사람에게 넘어갑니다.
*   **랜덤 타이머**: 폭탄은 **15초에서 40초 사이** 중 언제 터질지 아무도 모릅니다. (매 판마다 랜덤하게 바뀝니다!)
*   **긴장감 조성**: 시간이 지날수록 배경색이 무지개색으로 빠르게 변하며, 폭탄 아이콘이 흔들려 긴장감을 줍니다.

---

## 💥 당첨자 확인
*   타이머가 종료되면 화면이 강렬한 **빨간색**으로 변하며 "💥" 폭발 효과가 나타납니다.
*   최종적으로 화면에 이름이 떠 있는 사람이 **커피 당첨자(Winner)**입니다! 💸

---

## 💡 유용한 팁
*   **무음 모드**: 이 게임은 소리 없이 시각 효과만으로 진행되므로, 회의실이나 조용한 사무실에서도 안전하게 즐길 수 있습니다.
*   **순서 섞기**: 이름을 입력한 순서와 상관없이, 게임이 시작될 때 시스템이 자동으로 순서를 무작위로 섞어줍니다.
*   **다시 하기**: 결과 화면에서 [다시 하기] 버튼을 누르면 처음 명단 입력 화면으로 돌아갑니다.
